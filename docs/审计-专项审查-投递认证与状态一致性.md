### 复核通过（有防线、无发现，记录在案防重复怀疑）

- **玩家面 sender 伪造拦截**：发送身份强制取认证身份（`chat_validation.cc:117-122`）。
- **player directory 信任门**：非可信连接拒绝 bind/unbind（`player_directory.cc:511-514` DenyUntrusted）。
- **search 身份绑定**：查询强制绑定认证身份。
- **SameUser 越权覆盖**：改密/资料类操作比对目标与认证身份。
- **群内权限**：全部管理操作过 `RoleAtLeast`（MODERATOR+ 门槛，含禁言 2250）。
- **设备包身份盖章**：注册/更新以服务端会话身份为准的点（通知面除外——见 A1，该面根本没有会话身份）。
- **服务注册表 fail-closed**：空注册表时注入/转发拒绝而非放行。
