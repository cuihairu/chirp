# 简介

Chirp 是一个面向游戏的实时通信后端骨架。当前受支持的路径是 `gateway + auth + chat`;其余服务、SDK 和应用,除非 [能力矩阵](../CAPABILITY_MATRIX.md) 另有说明,都请按 experimental(试验性)、demo(演示)或 stub(占位)对待。当前构建基线是 C++23。

从这里开始:

- [Core](../CORE.md):当前契约与边界的浓缩版
- [快速上手](./getting-started.md):本地构建、Docker Compose 与冒烟测试
- [API 总览](../api/overview.md):包信封(envelope)、端点(endpoint)与消息流程
- [总体架构](../architecture.md):拓扑与架构评审
