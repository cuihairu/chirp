# Introduction

Chirp is a real-time communication backend skeleton for games. The currently supported path is `gateway + auth + chat`; all other services, SDKs and applications should be treated as experimental, demo or stub unless the [Capability Matrix](../CAPABILITY_MATRIX.md)) says otherwise. The current build baseline is C++23.
