> 状态:**设计稿,二审已通过**——非实现、非已交付能力。功能面与

> 03 好友页修订稿(来源游戏标签+筛选,重出两态截图)**已代决通过**(FW1016D,

> **06–10 五页为 CHIRP-UX-001 步骤二补稿**(2026-11-28,登录/建群/组队语音/设备/群设置,

- 视口基线:375×812,移动优先单列
- 视觉基调:近黑底(#0f1115 系)+ indigo 单 accent(#6366f1,与文档站品牌色同族)+ 胶囊按钮 + 圆形头像
- 占位原则:logo 为几何声波记号、头像为「色相散列首字母圆」,全部中性占位,不伪造真实标识
- 导航骨架:底部五页签(聊天/好友/组队/语音/设备)= 桌面 Rail 同源映射;**通知中心与「我的」不占页签**,分别从会话列表顶栏 🔔 与头像进入
- 页面文件与 HTML 内注释、每页头部注释块三处一致;截图由 `chrome-headless-shell` 生成(命令见文末)

## 页面清单与设计说明

### 01 会话列表(首页)— `01-sessions.html`

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(logo 占位 + 「Chirp 伴侣」+ 当前用户 ID/在线态 + 🔔 未读角标 + 头像入口)→ 双主操作胶囊钮(新的私聊/新建群组)→ 「私聊」「群聊」分组卡片列表 → 底部五页签 |
| 交互 | 行点按进聊天窗(全屏推入);🔔 进通知中心;头像进「我的」;两主操作各弹全屏 sheet(选用户/建群),与 web 同名对话框动作集一致 |
| 状态 | 未读角标数(indigo 胶囊)、最近消息预览(含「发送人: 」前缀的群聊预览)、时间戳(今天时刻/昨天)、presence 绿点;本稿未画置顶/折叠,属刻意不做(与 web 现状对齐) |

### 02 聊天窗口 — `02-chat.html`

| 维度 | 设计 |
| --- | --- |
| 布局 | 头部(返回 + 群名 + typing 副标题 + ⚙ 群设置)→ 「加载更早的消息」置顶 → 日期分隔胶囊 → 气泡流(他人靠左带头像/自己靠右 indigo)→ 输入条(表情 + 圆角输入域 + 圆形发送) |
| 交互 | 长按气泡 → 操作 sheet:快捷反应/编辑/撤回(web 悬停动作集原样翻译,不增不减);Enter 语义落为发送按钮;⚙ 进群设置 sheet |
| 状态 | typing 副标题(「bob 正在输入…」)+ 具象化三点气泡;自己消息「已读」回执 + 时刻;撤回态 = 系统提示行;回应 chip(赞×2/心)挂在气泡下缘 |

### 03 好友与游戏好友 — `03-friends.html`(`#game` 看第二态)

> 2026-10-07 审核修订:好友卡加「来自《XX》」来源游戏标签 + 来源筛选 chip 行(用户审核意见),重出截图发审中。

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(标题 + 「添加」)→ 分段控制[好友|游戏好友] → 好友视图:来源筛选 chip 行(全部/各游戏)→ 请求卡(接受/拒绝)→ 好友卡(在线/离线 + 来源标签 + 发消息)→ 「等待对方同意」卡;游戏好友视图:数据面说明条 → 名单卡(游戏内状态 chip + 来源标签) |
| 交互 | 分段点按切换(原型用 hash 演示);来源筛选 chip 点按过滤列表行(计数标签静态不联动,原型演示口径);「发消息」跳对应私聊并切回聊天页签(同 FriendsDialog 动作集);「添加」= 按 ID 加好友 sheet。**筛选而非分组**(交互成本裁决):好友列表主序是在线优先,presence 排序与按游戏分组正交冲突;筛选 chip 零重排成本,对列表序无侵入 |
| 状态 | ● 在线/○ 离线 presence;来源标签 = 描边弱化 chip「来自《XX》」,有来源才显示——按 ID 添加的好友无来源不显示(示例 frank);筛选到具体游戏时无来源行隐藏;请求行双按钮;发出未决 = 「待同意」chip;游戏好友 chip:「对局中」(绿)/「游戏大厅」(indigo)/离线文字。**数据面注记(未实现,如实记录)**:协议面当前无好友来源字段——落地需在社交面补来源字段或由 game 平面关系链推导,落地形态待拍板,不擅自扩协议。游戏好友语义 = 通过游戏内 SDK 结识的关系链视图,在线状态数据面为 chat 服务 game_presence,**不新增协议能力**;分段为纯视图切换,发消息落同一聊天平面 |

### 04 通知 — `04-notifications.html`

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(返回 + 标题 + 全部已读)→ 「今天/更早」分组通知流 → 「推送设置」卡(系统推送/免打扰时段/仅好友与群提及) |
| 交互 | 点通知跳对应源(消息→会话、请求→好友页、邀请→组队页);「全部已读」一键清角标;开关为设置面示意(与推送注册状态联动) |
| 状态 | 未读通知 = indigo 淡底高亮;类别 chip 四种:消息/好友/组队/系统;系统类示例 = 「推送已在安卓设备启用」(对应 RegisterDevice 成功事件)。推送链路语义同设备平面(app_gateway WS 5201);通知抑制规则同 `shouldNotifyFor`(隐藏且非当前频道才弹)。APNs/鸿蒙凭据为外部前置,落地前推送臂不可用——本页设计与通道无关 |

### 05 我的 — `05-profile.html`

| 维度 | 设计 |
| --- | --- |
| 布局 | 个人卡(72px 头像 + ID + 复制)→ 「在线设备」卡(本机标记/平台行/顶号警示条)→ 「设置」列表(通知设置→04/词库过滤开关/深色模式/关于)→ 退出登录(红色 ghost) |
| 交互 | 入口 = 会话列表顶栏头像(不占页签);「复制」抄 ID 供加好友;「通知设置」跳 04;设备行点按看详情;退出登录二次确认 |
| 状态 | 「本机」chip + presence 点;设备卡警示文案写明同型顶号契约:「同账号在他端登录会顶掉当前会话——踢线是终态,SDK 停止重连并弹回登录页」;词库过滤开关 = WordFilterSync 三端同契约;设备面与「设备」页签同源(OnlineDevicesDialog),为忠实 Rail 映射保留双入口 |

### 06 登录 — `06-login.html`(2026-11-28 补稿,待用户过目)

| 维度 | 设计 |
| --- | --- |
| 布局 | 全屏居中(无页签,未认证态)→ 品牌占位标识(几何声波,非真实 logo)+ 「登录到 Chirp」→ 「服务器」基址字段 + 五平面拼接说明 → 「用户 ID」字段 → 主操作「登录」胶囊 → 开发模式注记 |
| 交互 | harmony HostPage 语义并入登录单屏(首次启动展开服务器项,已配置后折叠);基址行内校验失败 = 红描边 + 「地址需以 ws:// 或 wss:// 开头」;登录中按钮换「登录中…」;连接失败红字「无法连接到服务器,请稍后再试」 |
| 状态 | 账号密码登录为协议面正式路径,当前各端实现为 scaffold 用户 ID 直登(开发模式)——**密码字段不虚构**,待后端凭据 UI 落地后按同版式追加;桌面/web LoginPage 同字段口径 |

### 07 新建群组 — `07-group-create.html`(2026-11-28 补稿,待用户过目)

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(返回 + 新建群组)→ 表单卡(群组名称必填 / 群描述可选)→ 「消息有效期」TTL 分段档位(1 天/7 天/30 天)→ 初始成员 chip 行(点 × 移除)+ 添加成员行 → 主操作「创建群组」→ 底层页签半透明示意(sheet 推入) |
| 交互 | 从会话列表「新建群组」按钮弹全屏 sheet;TTL 点选即换档;添加成员进选用户 sheet;创建中换「创建中…」,失败行内红字「创建群组失败」 |
| 状态 | 名称必填为空时创建钮置灰;协议面 TTL 为分钟数、上限 43200=30 天——**分段档位映射固定分钟值,自定义分钟输入档是否保留待拍板**(harmony 现状为自由分钟数输入);桌面 Dialogs 建群对话框同字段 |

### 08 组队语音 — `08-party-voice.html`(2026-11-28 补稿,待用户过目)

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(返回 + 组队语音 + 服务连接态副标题)→ 「组队」卡(房间名/房间 ID/队长 chip + 成员名单状态 chip + 邀请/解散操作行)→ 「语音 · 房间 ID」卡(成员说话态名单 + 静音/拒听双开关行 + 退出房间)→ 协议面注记 → 底部页签(组队/语音双入口落同页) |
| 交互 | 邀请按对方用户 ID;准备/取消准备按行切换;移出/转让队长按行操作;解散二次确认「解散整个队伍?」;静音/拒听开关即时切换;退出房间二次确认「退出这个语音房间?」 |
| 状态 | 成员行 chip:待接受(灰)/已准备(绿)/队长(indigo);语音行:说话中(presence 点亮)/已静音/拒听(warn);空态「还没有加入队伍,创建一个或等待邀请。」「未在语音房间中,创建或加入一个。」;服务未连接降级「组队服务未连接/语音服务未连接」;**音频媒体面未接入,不画频谱/波形装饰**(协议面名单口径,harmony 同文注记) |

### 09 设备 — `09-devices.html`(2026-11-28 补稿,待用户过目)

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(返回 + 设备 + 服务态副标题)→ 「本设备」卡(机型/平台 + 登录时间 + 推送注册态 chip)→ 「在线设备」卡(同账号他端:在线 presence/离线态 + 移除)→ 顶号契约注记 → 「偏好」行(游戏在线状态开关)→ 推送链路注记 → 底部页签 |
| 交互 | 他端行点按重命名/移除;移除 = 顶掉该端会话(终态,二次确认);开关即时生效,失败「设置未保存,请稍后重试」 |
| 状态 | 推送注册 chip 两态:已注册(indigo)/未注册(灰 + 行内引导);空态「当前没有其他在线端。」;服务未连接降级「设备服务未连接」;**如实注记:离线消息推送当前为日志传输,真实厂商推送待接入**(APNs/FCM 凭据外部前置);顶号契约文案与 05 我的页设备卡同口径 |

### 10 群设置 — `10-group-settings.html`(2026-11-28 补稿,待用户过目)

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(返回 + 群设置 + 群名/人数副标题)→ 「群信息」卡(群头像占位/名称/描述 + 我的群昵称行)→ 「成员」卡(名单 + 角色 chip + 禁言态 + 行内操作 + 添加成员行)→ 「管理」行(退出群组/解散群组双危险键并排)→ 底层页签半透明示意 |
