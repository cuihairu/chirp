# Chirp 手机端原型(移动通用稿)

> 状态:**设计稿,等用户审核**——非实现、非已交付能力。功能面与
> `docs/design-notes/app_chat_prototype.md`「三、手机端原型」同源,
> 不新增任何协议能力;审核通过前,不进文档站轮播、不在 README/能力矩阵引用。
> 平台口径:iOS/鸿蒙为低优先级填空(用户令 2026-10-05),本稿只出移动通用设计,不写平台实现。

- 视口基线:375×812,移动优先单列
- 视觉基调:近黑底(#0f1115 系)+ indigo 单 accent(#6366f1,与文档站品牌色同族)+ 胶囊按钮 + 圆形头像
- 占位原则:logo 为几何声波记号、头像为「色相散列首字母圆」,全部中性占位,不伪造真实标识
- 导航骨架:底部五页签(聊天/好友/组队/语音/设备)= 桌面 Rail 同源映射;**通知中心与「我的」不占页签**,分别从会话列表顶栏 🔔 与头像进入
- 页面文件与 HTML 内注释、每页头部注释块三处一致;截图由 `chrome-headless-shell` 生成(命令见文末)

## 页面清单与设计说明

### 01 会话列表(首页)— `01-sessions.html`

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(logo 占位 + 「Chirp 伴侣」+ 当前用户 ID/在线态 + 🔔 未读角标 + 头像入口)→ 双主操作胶囊钮(新的私聊/新建群组)→ 「私聊」「群聊」分组卡片列表 → 底部五页签 |
| 交互 | 行点按进聊天窗(全屏推入);🔔 进通知中心;头像进「我的」;两主操作各弹全屏 sheet(选用户/建群),与 web 同名对话框动作集一致 |
| 状态 | 未读角标数(indigo 胶囊)、最近消息预览(含「发送人: 」前缀的群聊预览)、时间戳(今天时刻/昨天)、presence 绿点;本稿未画置顶/折叠,属刻意不做(与 web 现状对齐) |

### 02 聊天窗口 — `02-chat.html`

| 维度 | 设计 |
| --- | --- |
| 布局 | 头部(返回 + 群名 + typing 副标题 + ⚙ 群设置)→ 「加载更早的消息」置顶 → 日期分隔胶囊 → 气泡流(他人靠左带头像/自己靠右 indigo)→ 输入条(表情 + 圆角输入域 + 圆形发送) |
| 交互 | 长按气泡 → 操作 sheet:快捷反应/编辑/撤回(web 悬停动作集原样翻译,不增不减);Enter 语义落为发送按钮;⚙ 进群设置 sheet |
| 状态 | typing 副标题(「bob 正在输入…」)+ 具象化三点气泡;自己消息「已读」回执 + 时刻;撤回态 = 系统提示行;回应 chip(赞×2/心)挂在气泡下缘 |

### 03 好友与游戏好友 — `03-friends.html`(`#game` 看第二态)

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(标题 + 「添加」)→ 分段控制[好友|游戏好友] → 好友视图:请求卡(接受/拒绝)→ 好友卡(在线/离线 + 发消息)→ 「等待对方同意」卡;游戏好友视图:数据面说明条 → 名单卡(游戏内状态 chip) |
| 交互 | 分段点按切换(原型用 hash 演示);「发消息」跳对应私聊并切回聊天页签(同 FriendsDialog 动作集);「添加」= 按 ID 加好友 sheet |
| 状态 | ● 在线/○ 离线 presence;请求行双按钮;发出未决 = 「待同意」chip;游戏好友 chip:「对局中」(绿)/「游戏大厅」(indigo)/离线文字。游戏好友语义 = 通过游戏内 SDK 结识的关系链视图,在线状态数据面为 chat 服务 game_presence,**不新增协议能力**;分段为纯视图切换,发消息落同一聊天平面 |

### 04 通知 — `04-notifications.html`

| 维度 | 设计 |
| --- | --- |
| 布局 | 顶栏(返回 + 标题 + 全部已读)→ 「今天/更早」分组通知流 → 「推送设置」卡(系统推送/免打扰时段/仅好友与群提及) |
| 交互 | 点通知跳对应源(消息→会话、请求→好友页、邀请→组队页);「全部已读」一键清角标;开关为设置面示意(与推送注册状态联动) |
| 状态 | 未读通知 = indigo 淡底高亮;类别 chip 四种:消息/好友/组队/系统;系统类示例 = 「推送已在安卓设备启用」(对应 RegisterDevice 成功事件)。推送链路语义同设备平面(app_gateway WS 5201);通知抑制规则同 `shouldNotifyFor`(隐藏且非当前频道才弹)。APNs/鸿蒙凭据为外部前置,落地前推送臂不可用——本页设计与通道无关 |

### 05 我的 — `05-profile.html`

| 维度 | 设计 |
| --- | --- |
| 布局 | 个人卡(72px 头像 + ID + 复制)→ 「在线设备」卡(本机标记/平台行/顶号警示条)→ 「设置」列表(通知设置→04/词库过滤开关/深色模式/关于)→ 退出登录(红色 ghost) |
| 交互 | 入口 = 会话列表顶栏头像(不占页签);「复制」抄 ID 供加好友;「通知设置」跳 04;设备行点按看详情;退出登录二次确认 |
| 状态 | 「本机」chip + presence 点;设备卡警示文案写明同型顶号契约:「同账号在他端登录会顶掉当前会话——踢线是终态,SDK 停止重连并弹回登录页」;词库过滤开关 = WordFilterSync 三端同契约;设备面与「设备」页签同源(OnlineDevicesDialog),为忠实 Rail 映射保留双入口 |

## 刻意不设计的面

- 语音媒体面 UI(信令之外未验证——与桌面同一现状口径,见原型文档语音页 ⚠)
- 组队页/语音页/设备页/登录页的独立手机稿:本批按用户指定五页出图;其余屏的线框仍以 `app_chat_prototype.md` ASCII 稿为准,审核通过后可按同 token 体系补齐
- 推送通道凭据(APNs 需 Apple 开发者凭据、鸿蒙需 ArkTS 工具链——外部前置登记在案)
